## 新增功能

- 新增“系统字体”，支持分别选择中文、西文和等宽字体，三个选项独立保存，不参与一键启用。中文和西文默认跟随系统，等宽字体默认使用 Maple Mono。
- 内置思源黑体、Inter、Manrope、Maple Mono、JetBrains Mono、Fira Code 和 Cascadia Code，并支持导入 TTC、TTF、OTF 字体，每项最多 100 MiB。支持字体集合、真实字重、斜体和可变字重匹配；导入失败或取消时保留原选择。
- 适配 Flyme 主题字体处理，避免所选字体及等宽字形被主题字体覆盖。首次安装后请打开模块完成字体同步；修改字体需重启 Zygote 生效，已有应用也需重启。网页字体覆盖取决于相关应用和独立渲染进程是否得到框架注入。

## 体验优化

- 系统字体入口使用 Flyme 设置原生图标，重启提示直接显示在字体页面的分组副标题中，更换成功后不再弹出提示。
- 调整首页、设置分类以及应用列表的滚动容器，统一沿用现有的边缘回弹和卡片样式。
