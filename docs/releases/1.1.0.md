## 新增功能

- 新增 **ColorOS 堆叠多任务**：默认让前一个任务居中，当前任务位于右侧；左侧卡片逐渐靠拢、缩小、淡出并模糊，右侧卡片逐渐放大且间距递增，不显示底部应用图标跑马灯。
- 堆叠多任务支持从应用或桌面同步入场，位置与缩放同时过渡，提前隐藏状态栏；按压不改变卡片目标缩放，保留下拉回弹，并维持正确的叠放次序。
- 堆叠多任务采用延后模糊、视图裁剪和缩略图按需加载，减少入场及任务切换期间的开销；远处卡片先淡出再隐藏，应用名称提前淡出。
- 将控制中心配色设置改为 **控制中心 ColorOS 样式**，提供“不修改”“全新焕彩”“自选颜色”。原有开启状态自动迁移为“全新焕彩”。
- 自选颜色提供与 ColorOS Mod 一致的颜色选择器及 RGB/ARGB 输入，默认色为 **#80E6F2FF**。2×1 卡片保持空心样式，激活态圆形背景及普通磁贴使用所选颜色，前景图标和文字为白色；音量和亮度保持各自的配色。
- 新增 **ColorOS 通知轮廓光**，在通知背景上绘制与控制中心一致的轮廓效果，适配通知圆角、展开、裁切及背景透明度。
- 新增 **非压感 mBack 跟随系统长按超时**，跟随系统长按超时及模块中的对应设置，压感机型维持原行为。
- 新增独立 **安装器** APK：无桌面图标，使用默认应用图标，支持 APK 文件打开与分享入口，通过 Shizuku 授权完成安装及覆盖更新，并以系统实际安装结果显示成功或失败。

## 改进与修复

- 统一控制中心内容显隐阈值，使用固定时长的行间动画，避免过度下拉后反向上拉时内容反复出现或消失；打断动画时从当前状态继续。
- 改善合并控制中心的帧率请求，展开时请求当前分辨率支持的最高刷新率，关闭后恢复系统策略；减少逐帧重复缩放、回弹动画对象创建、通知位移重复更新及二次展开时的布局查找。
- 放大控制区域时依据实际内容宽度限制缩放，不超过屏幕宽度减 40dp；合并控制中心通知宽度与上方控制区域一致，并取消网络卡片重复缩放。
- 修复浮动通知转入通知中心后仍保留较大宽度的问题。
- 补全通知展开态、浮动态和固定高度内容的额外内边距补偿，避免内容与操作按钮高度不足。
- 修复“多任务隐藏未在运行的应用”复用旧任务缓存的问题，刷新任务状态并防止编译内联绕过过滤；分屏组合仍有任务在运行时予以保留。
- 修复首次安装时“一键启用”被原有系统设置误判为已开启的问题；将堆叠多任务加入一键启用范围，并同步更新控制中心样式状态。
- 修复 ColorOS 样式 2×1 磁贴按压时圆形背景短暂被裁成方形的问题，保留系统原有按压回弹。
- 缩小全部 Fluix 下拉菜单宽度至 200dp，增加菜单项最小高度至 56dp。
- 按 Flyme AIOS 参考图重绘首页 Banner 背景，保留橙红色曲面及柔和光影，去除原图的数字、标志与宣传文字；设备名和系统版本继续由界面显示。

本次发布同时提供 Flyme Mod 与独立安装器 APK；发布流水线优先采用按重要程度整理的版本说明，并同步至两个发布仓库。
