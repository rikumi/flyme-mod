# Flyme Mod

> Module ID: `dev.rikumi.flymemod`

一个针对 Flyme 的全方位体验增强模块，提供桌面、控制中心、通知中心与状态栏、锁屏和系统净化等功能，改善系统界面与交互体验。

本项目为 [ColorOS Mod](https://github.com/Xposed-Modules-Repo/com.rikumi.colorosmod) 姊妹项目。

**请同时给 [Xposed 模块仓库](https://github.com/Xposed-Modules-Repo/dev.rikumi.flymemod) 一个 Star！**

## 目前主要功能

### 桌面

#### 桌面图标设置

- 允许编辑图标和名称
- 允许隐藏应用，在桌面图标长按菜单中增加 Flyme 风格的隐藏按钮
- 桌面双指张开查看隐藏应用，仅在非编辑、非文件夹的常规桌面状态生效

#### 壁纸设置

- 修复开机时壁纸强制调暗

#### 桌面动画设置

- 恢复关闭到文件夹动画目标
- 修复启动时锁屏小组件异常显示

#### 桌面文件夹设置

- 桌面文件夹水平分页
- 桌面文件夹垂直居中
- 恢复文件夹背景色
- 调整文件夹圆角大小

### 控制中心

#### 控制中心背景

- 控制中心背景压暗
- 自定义背景模糊半径

#### 控制中心主题

- ColorOS 轮廓光
- 控制中心磁贴亮色背景及透明度调节
- 控制中心全新焕彩样式及自选颜色
- 音量/亮度条激活区域圆角
- 定制控制中心时钟字体、字重和等宽显示
- 控制中心时钟日期上移
- 控制中心设置按钮上移

#### 控制中心布局

- 隐藏农历日期
- 无线网络替换为 Wi-Fi
- 控制中心操作区域放大
- 恢复合并控制中心折叠状态磁贴高度
- 网络卡片分离为 Wi-Fi 和蓝牙
- 分离网络卡片折叠吞并同行未播放音乐控制
- 动画式斜划线静音图标
- 2×1 卡片文字布局优化
- 1×1 磁贴改为圆形

#### 控制中心动画

- 修复控制中心开启/关闭动画
- 修复控制中心位移基准点
- 修复合并控制中心上拉动画起始位置
- 修复合并控制中心二次展开动画
- 合并控制中心清空通知后保持开启

#### 音量调节设置

- 修改音量调节前四小格，合并为两中格或一大格

### 通知中心与状态栏

#### 通知中心设置

- 增加浮动通知宽度
- ColorOS 通知轮廓光
- 增大通知圆角
- 恢复原生通知下滑展开
- 通知操作按钮改为黑白色
- 禁用 Google 通知建议操作

#### 状态栏设置

- 恢复原生第三方通知图标
- 合并双卡信号
- 独立显示网络制式
- 隐藏睡眠模式、VPN、定位、蓝牙、投屏、热点、屏幕录制、摄像头使用和麦克风使用图标
- 定制状态栏字体、字重、等宽显示和字间距

### 锁屏

#### 锁屏视觉

- 隐藏锁屏和通知中心运营商
- 限制息屏显示移动范围
- 定制锁屏和息屏时钟字体、字重、等宽显示和字间距

### 隐藏应用

- 从桌面彻底隐藏任意应用
- 查看并启动隐藏的应用，不影响应用功能
- 4 行×3 列横向分页，点击图标打开应用，长按可查看应用信息或取消隐藏

### 停用应用

- 在应用管理中隐藏已停用的应用
- 查看已停用及用户级卸载应用，并导出为脚本

### 导航与手势

#### 手势行为

- 应用导航栏强制沉浸，可选择多个非系统应用，默认选择微信，由 SystemUI 实现
- 修改系统长按超时
- 微调系统动画时长
- 非压感 mBack 跟随系统长按超时
- 未安装助手长按 mBack 回桌面

#### 多任务切换

- ColorOS 堆叠多任务
- 多任务上划彻底结束进程
- 多任务隐藏未在运行的应用
- 修改小窗数量上限，默认 3 个，支持同时显示与独立操作多个小窗

### 系统净化

#### 应用商店净化

- 屏蔽开屏广告
- 去除精选 Tab 和游戏 Tab
- 去除首页全部内容
- 去除我的页、应用详情页、下载管理页和应用更新页推荐
- 去除搜索框热词及搜索页推荐

#### 天气

- 去除天气应用贴片广告
- 屏蔽生活建议页内容推荐
- 天气首页背景压暗

#### 应用安装器

- 跳过安装警告

### 相机与杂项

#### 相机设置

- 图库预览跟随系统旋转锁定
- 保留滤镜设置

#### 系统杂项

- 深色应用管理支持选择特殊应用
- 横屏游戏宽度适配，可为非系统应用分别选择避开挖孔居中、16:9 居中等模式
- 21:9 机型支持 18:9 居中和 19.5:9 居中；20:9 机型支持 19.5:9 拉伸
- 横屏适配窗口的小窗比例同步调整；除拉伸模式外，缩窄窗口应用 8dp 圆角

### 存储管理

- 可选择不自动创建媒体文件夹：Alarms、Audiobooks、Movies、Notifications、Podcasts、Recordings、Ringtones
