# Flyme Mod

> Module ID: `dev.rikumi.flymemod`

一个针对 Flyme 的全方位体验增强模块，提供桌面、控制中心、通知中心与状态栏、锁屏和系统净化等功能，改善系统界面与交互体验。

本项目为 [ColorOS Mod](https://github.com/Xposed-Modules-Repo/com.rikumi.colorosmod) 姊妹项目。

**请同时给 [Xposed 模块仓库](https://github.com/Xposed-Modules-Repo/dev.rikumi.flymemod) 一个 Star！**

## 目前主要功能

### 桌面

#### 轮廓光

- 图标轮廓光，先沿图标底部绘制极浅灰色内阴影，再沿实际图标透明轮廓使用控制中心及通知中心的轮廓光 shader；不对图标内部纹理增加高亮或光晕，随按压缩放，并跟随返回桌面的图标动画淡入、移动和缩放，覆盖图标设置界面的桌面预览、主题/图标包选择器预览，以及编辑图标弹窗和自建选择界面的图标，并统一控制文件夹轮廓光、编辑状态上下操作按钮轮廓光；开启后顶部按钮圆角增加 4dp；共用算法保留原有线宽与渐变效果，仅按背景宽高和圆角范围限制高光长度；圆形磁贴的高光延伸至顶部两侧约 45°
- 长按菜单轮廓光，与控制中心及通知中心共用轮廓光 shader，仅覆盖上下边缘及圆角，同时覆盖编辑图标弹窗、选择图标界面与图标包下拉菜单的背景；开启时隐藏原生长按菜单箭头（包含弹簧展开动画）
- 小组件背景轮廓光，与控制中心及通知中心共用轮廓光 shader，仅描绘原生模糊背景或尺寸最大的背景（支持半透明与不透明背景），不描绘内部文字和按钮

#### 桌面图标设置

- 修复选择图标包图标显示：第三方图标包在选择器中使用内置或按图标包规则合成的系统设置图标预览，未保存选择时默认开启
- 恢复“下滑呼出”设置菜单的取消按钮
- 允许编辑图标和名称
- 系统级应用图标包图标：未保存选择时默认开启。跟随桌面当前图标包，依次匹配入口 Activity、同包首个图标，未命中时使用原生图标；保留原图配色、图标类型和用户徽章。切换图标包或安装、更新、卸载应用后在后台更新全应用缓存，界面读取不等待图标服务。支持最近任务、应用管理、模块及第三方应用的常用图标读取；第三方目标需手动加入 LSPosed 作用域。跨用户读取、系统或主题图标保持原生，应用自行缓存的旧图标需重新获取。
- 允许隐藏应用，在桌面图标长按菜单中增加 Flyme 风格的隐藏按钮
- 桌面双指张开查看隐藏应用，仅在非编辑、非文件夹的常规桌面状态生效

#### 桌面文件夹设置

### 导航与手势

#### 导航与返回

- 应用导航栏强制沉浸，可选择多个非系统应用，默认选择微信，由 SystemUI 实现
- 放宽侧滑返回判定：开启后，整个有效侧边区域（默认 24dp，包含原生 12dp 区域）均按首个非零移动的纵横比 5:1 判定返回；保留原生最小位移、超时、反向取消及其他区域限制，关闭时恢复原生判定，未保存选择时默认开启
- 侧边返回暗色背景：将返回曲线内部填充改为半透明黑色，不透明度为 0–100%，默认 50%，步长 5%；未保存选择时默认开启，关闭后恢复原生填充，边缘线保持原样

#### 长按操作

#### 动画设置

- 微调系统动画时长

#### 多任务切换

- 修正多任务卡片圆角尺寸，未保存开关选择时默认启用，已保存的关闭选择保持；开启后可在 10–90dp 调整截图和背景的圆角；数值按完整应用窗口的逻辑 dp 换算一次像素，再按实际卡片与任务尺寸比例映射到局部裁切坐标，避免将屏幕级半径直接套入缩小卡片，随原生进入/退出多任务动画插值，保留全屏窗口端圆角及截图白边的一致裁切；首次默认值读取当前显示屏的系统硬件圆角，按其逻辑密度换算为 dp 后向上取最近偶数，再限制到滑条范围；已保存的手动数值不变，不同角大小不同时取最小的非零值；系统未提供圆角信息时暂用 10dp 且不写入硬件默认值，后续继续尝试读取

- 多任务上划彻底结束进程
- 多任务隐藏未在运行的应用

### 相机与杂项

#### 相机设置

- 图库预览跟随系统旋转锁定
- 调整动态照片向前追溯时长：在相机原有拍摄前片段上额外增加 0–1 秒，每步 0.1 秒，默认增加 0.5 秒；前段增加的时长从后段等量扣除，保持原有总时长；开关默认关闭，关闭后恢复原有缓存策略。预览刚启动或滤镜、镜头切换后，可用片段长度受已缓存画面限制。
- 关闭自动夜景：仅作用于自动拍照，保留手动选择夜景模式。默认关闭。
- 调整夜景曝光时间：开启后可通过滑条设置夜景模式的目标总曝光时间，范围为 0.5–10 秒，每步 0.1 秒，默认值为 3 秒；实际时间受相机硬件与算法限制。关闭后恢复相机原有曝光策略。
- 保留滤镜设置

#### 系统杂项

- 修复重启系统服务后解锁卡顿：未保存选择时默认开启，并纳入一键启用；开启后避免 Zygote 重启时重复等待 APEX 开机通知，真实开机及待确认更新保持原生处理

- 深色模式系统应用背景纯黑：将支持系统应用的页面及启动背景改为纯黑，覆盖电话、信息、图库、独立电池设置及应用管理等页面，并处理应用商店分类侧栏；保留未纳入适配的卡片和分组配色。弹窗、浮层、浮动页面及系统未响应对话框保持原生背景。模块界面同步支持纯黑页面背景。仅深色模式下生效，关闭后需重启相关目标应用刷新已缓存资源；独立电池设置应用需加入 LSPosed 作用域。
- 修复无线调试配对页面主题适配：杂项中的独立开关，首次默认开启，保留已保存的开关选择；开启后，深色模式下提亮无线调试授权框及配对框中偏暗的中性文字，保留按钮强调色、错误色、控件状态及原生背景；已配对设备设置图标的末端留白缩至最多 16dp。浅色模式与其它弹窗不受文字修复影响。
- 系统 ANR（应用未响应）弹窗使用 ROM 原生深浅色背景、圆角和遮罩，并排除纯黑背景覆盖。
- 强制显示设置首页 Google：首次默认开启，保留已保存的开关选择；安装且启用 Google 服务设置组件后，可在国内版设置首页恢复真实 Google 设置入口，不受国际版显示条件限制；未安装或组件不可用时不生成空入口，关闭后恢复 ROM 原生显示规则。

- 强制深色适配使用白名单：未保存选择时默认开启，初始白名单为空；只有在深色应用管理中明确开启的包使用 Flyme 强制深色。单项和批量操作同时维护白名单与原生黑名单，关闭后恢复 ROM 黑名单策略，不影响应用自身夜间主题；目标应用需加入 LSPosed 作用域。
- 强制深色黑名单支持关闭特殊应用：增加系统应用及无桌面入口应用的管理，DocumentsUI、Google Play 服务保持可选，排除已经适配深色模式的系统应用。开启后，已加入 LSPosed 作用域的目标进程响应黑名单变化并关闭 Flyme 强制深色转换，保留应用自身夜间主题及已保存选择。
- 横屏游戏宽度适配，可为非系统应用分别选择避开挖孔居中、16:9 居中等模式
- 21:9 机型支持 18:9 居中和 19.5:9 居中；20:9 机型支持 19.5:9 拉伸
- 横屏适配窗口的小窗比例同步调整；除拉伸模式外，缩窄窗口应用 8dp 圆角

- 首页采用 Flyme 气球标志，显示设备名称和系统版本；启动图标使用白色背景与居中的气球前景

- 重启 Zygote，保留为独立菜单操作
