# Flyme Mod

> Module ID: `dev.rikumi.flymemod`

一个针对 Flyme 的全方位体验增强模块，提供桌面、控制中心、通知中心与状态栏、锁屏和系统净化等功能，改善系统界面与交互体验。

本项目为 [ColorOS Mod](https://github.com/Xposed-Modules-Repo/com.rikumi.colorosmod) 姊妹项目。

**请同时给 [Xposed 模块仓库](https://github.com/Xposed-Modules-Repo/dev.rikumi.flymemod) 一个 Star！**

## 目前主要功能

### 桌面

#### 桌面图标设置

- 图标轮廓光，先沿图标底部绘制极浅灰色内阴影，再沿实际图标形状使用控制中心及通知中心的轮廓光 shader，随按压缩放；共用算法保留原有线宽与渐变效果，仅按背景宽高和圆角范围限制高光长度；圆形磁贴的高光延伸至顶部两侧约 45°
- 长按菜单轮廓光，与控制中心及通知中心共用轮廓光 shader，仅覆盖上下边缘及圆角，开启时隐藏菜单箭头（包含弹簧展开动画）
- 允许编辑图标和名称
- 允许隐藏应用，在桌面图标长按菜单中增加 Flyme 风格的隐藏按钮
- 桌面双指张开查看隐藏应用，仅在非编辑、非文件夹的常规桌面状态生效

#### 桌面文件夹设置

- 桌面文件夹水平分页
- 桌面文件夹垂直居中
- 修复文件夹长按菜单对齐，按文件夹背景实际左右边界对齐菜单
- 文件夹背景轮廓光，与控制中心及通知中心共用轮廓光 shader；背景显隐及透明度变化时同步重绘，包括从应用返回桌面
- 恢复文件夹背景色
- 调整文件夹圆角大小

#### 桌面小组件设置

- 小组件背景轮廓光，与控制中心及通知中心共用轮廓光 shader，仅描绘原生模糊背景或尺寸最大的背景（支持半透明与不透明背景），不描绘内部文字和按钮

#### 壁纸设置

- 修复开机时壁纸强制调暗

#### 桌面动画设置

- 恢复关闭到文件夹动画目标
- 修复启动时锁屏小组件异常显示

### 控制中心

#### 控制中心背景

- 控制中心背景压暗
- 自定义背景模糊半径

#### 控制中心主题

- ColorOS 轮廓光
- 控制中心磁贴亮色背景及透明度调节
- 控制中心磁贴背景增色及饱和度提高量调节
- 控制中心磁贴圆角大小
- 控制中心全新焕彩样式及自选颜色
- 音量/亮度条激活区域圆角
- 1×1 磁贴强制圆形（优先于自定义磁贴圆角）

#### 控制中心时钟

- 定制控制中心时钟字体、字重和等宽显示
- 控制中心时钟日期上移

- 隐藏农历日期

#### 控制中心布局

- 增大合并控制中心通知宽度，添加居中半透明分隔条及上下间距

- 控制中心操作区域放大
- 恢复合并控制中心折叠状态磁贴高度
- 合并中心不重要通知按钮替换为设置
- 网络卡片分离为 Wi-Fi 和蓝牙
- 分离网络卡片折叠吞并同行未播放音乐控制
- 无线网络替换为 Wi-Fi
- 动画式斜划线静音图标
- 2×1 卡片文字布局优化
- 控制中心设置按钮上移

#### 控制中心动画

- 修复控制中心开启/关闭动画
- 修复控制中心位移基准点
- 修复合并控制中心上拉动画起始位置
- 修复合并控制中心二次展开动画
- 合并控制中心清空通知后保持开启

#### 音量调节设置

- 修改音量调节前四小格，合并为两中格或一大格

### 通知中心与状态栏

#### 通知中心主题

- 通知亮色背景（弹出通知统一保持暗色）
- 通知背景增色及饱和度提高量调节（与磁贴滤镜重叠时取并）
- 通知圆角大小
- ColorOS 通知轮廓光

#### 通知中心设置

- 增加浮动通知宽度
- 修复已读通知动画层级
- 恢复原生通知下滑展开
- 通知操作按钮改为黑白色
- 去除通知操作栏的特殊背景
- 禁用 Google 通知建议操作

#### 状态栏图标

- 恢复原生第三方通知图标
- 合并双卡信号
- 独立显示网络制式

#### 状态栏图标隐藏

- 隐藏睡眠模式、VPN、定位、蓝牙、投屏、热点、屏幕录制、摄像头使用和麦克风使用图标

#### 状态栏字体

- 定制状态栏字体、字重、等宽显示和字间距

### 锁屏

#### 锁屏操作

- 屏蔽锁屏长按编辑

#### 锁屏视觉

- 隐藏锁屏和通知中心运营商
- 限制息屏显示移动范围
- 定制锁屏和息屏时钟字体、字重、等宽显示和字间距

### 隐藏应用

- 从桌面彻底隐藏任意应用
- 查看并启动隐藏的应用，不影响应用功能
- 4 行×3 列横向分页，点击图标打开应用，长按可查看应用信息或取消隐藏

### 停用应用

- 在应用管理中隐藏已停用的应用
- 查看已停用及用户级卸载应用，并导出为脚本

### 导航与手势

#### 导航与返回

- 应用导航栏强制沉浸，可选择多个非系统应用，默认选择微信，由 SystemUI 实现
- 调整返回手势区宽度：以 dp 调整，默认值及上限由原生手势宽度的 1 倍及 2 倍换算，旧倍率自动迁移；调整时显示蓝色半透明手势区预览

#### 长按操作

- 修改系统长按超时
- 非压感 mBack 跟随系统长按超时
- 未安装助手长按 mBack 回桌面

#### 动画设置

- 微调系统动画时长
- 限制回桌面动画最小图标尺寸

#### 多任务切换

- ColorOS 堆叠多任务
- 多任务上划彻底结束进程
- 多任务隐藏未在运行的应用

#### 小窗管理

- 修改小窗数量上限，默认 3 个，支持同时显示与独立操作多个小窗

### 系统净化

#### 应用商店净化

- 屏蔽开屏广告
- 去除精选 Tab 和游戏 Tab
- 去除首页全部内容
- 去除我的页、应用详情页、下载管理页和应用更新页推荐
- 独立去除我的页面的我的预约及心愿单、福利活动及快应用、手机瘦身入口（默认关闭，更改后重新启动应用商店）
- 去除搜索框热词及搜索页推荐

#### 天气

- 去除天气应用贴片广告
- 屏蔽生活建议页内容推荐
- 天气首页背景压暗

#### 应用安装器

- 跳过安装警告

### 相机与杂项

#### 相机设置

- 图库预览跟随系统旋转锁定
- 调整动态照片向前追溯时长：在相机原有拍摄前片段上额外增加 0–1 秒，每步 0.1 秒，默认增加 0.5 秒；前段增加的时长从后段等量扣除，保持原有总时长；开关默认关闭，关闭后恢复原有缓存策略。预览刚启动或滤镜、镜头切换后，可用片段长度受已缓存画面限制。
- 关闭自动夜景：仅作用于自动拍照，保留手动选择夜景模式。默认关闭。
- 调整夜景曝光时间：开启后可通过滑条设置夜景模式的目标总曝光时间，范围为 0.5–10 秒，每步 0.1 秒，默认值为 3 秒；实际时间受相机硬件与算法限制。关闭后恢复相机原有曝光策略。
- 保留滤镜设置

#### 系统杂项

- 深色模式系统应用背景纯黑：将全局背景的新旧两种灰黑色（#0B0B0C、#232323）替换为纯黑，时钟按其明确声明的旧样式全局背景处理，应用商店按已确认的旧样式及页面容器处理，分类侧栏背景覆盖为纯黑，分组、卡片和其他灰色保留；默认关闭，仅在目标应用深色模式下生效，并保留透明度。模块界面同步使用纯黑页面背景，切换后即时更新，分组和卡片维持原配色。关闭后应重启其他目标应用刷新已缓存资源。
- 自定义系统主题色：依据 MEIZU 22 应用资源中的包名与主题颜色资源名，核对各应用的实际主题继承关系，每个应用仅替换红、黄、蓝、绿、橙中的一种主色及其浅深色变体，保留透明度和中性色状态；内置界面图标的彩色部分也使用所选颜色，保留白色细节。桌面通知计数及删除、卸载等图标保持原样；其他主色未确认为红色的应用，删除、警告等操作图标保留原有红色；相机和文件管理不参与主题色替换。无法确认主题主色的应用保留普通控件颜色，图标染色独立处理。图库 tab 的选中态文字与动画图标跟随所选颜色；安装器升级图标的白色部分镂空、蓝色部分使用主题色；应用商店选中 tab 图标的白色部分镂空，其他部分使用所选颜色，未选中图标保留灰白色。模块自身的控件强调色和首页分类图标同步使用所选颜色，保存颜色或切换开关后即时更新，关闭后恢复原配色。颜色选择采用连续 HSV 与透明度滑条，并保留十六进制输入。默认关闭，推荐作用域限于有桌面入口或影响多个界面的应用，并保留相机等已有功能所需的包；Wi-Fi、蓝牙和热点的独立连接设置进程同样应用主题色及纯黑背景；首页在启动及返回时检查作用域，存在遗漏时显示可启动 LSPosed 管理器的黄色警告。更换颜色或关闭后，应重启目标应用刷新已缓存控件。

- 深色应用管理支持选择特殊应用
- 横屏游戏宽度适配，可为非系统应用分别选择避开挖孔居中、16:9 居中等模式
- 21:9 机型支持 18:9 居中和 19.5:9 居中；20:9 机型支持 19.5:9 拉伸
- 横屏适配窗口的小窗比例同步调整；除拉伸模式外，缩窄窗口应用 8dp 圆角

### 存储管理

- 可选择不自动创建媒体文件夹：Alarms、Audiobooks、Movies、Notifications、Podcasts、Recordings、Ringtones
