# Flyme Mod

> Module ID: `dev.rikumi.flymemod`

一个针对 Flyme 的全方位体验增强模块，提供桌面、控制中心、通知中心与状态栏、锁屏和系统净化等功能，改善系统界面与交互体验。

本项目为 [ColorOS Mod](https://github.com/Xposed-Modules-Repo/com.rikumi.colorosmod) 姊妹项目。

**请同时给 [Xposed 模块仓库](https://github.com/Xposed-Modules-Repo/dev.rikumi.flymemod) 一个 Star！**

## 目前主要功能

### 桌面体验优化

- 桌面文件夹水平分页
- 桌面文件夹垂直居中
- 恢复文件夹背景色
- 调整文件夹圆角大小
- 降低回桌面上抛阻尼
- 恢复关闭到文件夹动画目标
- 修复开机时壁纸强制调暗

### 控制中心体验优化

- 控制中心操作区域放大
- 隐藏农历日期
- 无线网络替换为 Wi-Fi
- 2x1 卡片文字布局优化
- 网络卡片分离为 Wi-Fi 和蓝牙
- 分离网络卡片折叠吞并同行未播放音乐控制
- 2x1 卡片改为实心（HyperOS 模式）
- 1x1 磁贴改为圆形
- 恢复合并控制中心折叠状态磁贴高度
- 定制控制中心时钟字体、字重
- 控制中心时钟日期上移
- 控制中心设置按钮上移
- 控制中心磁贴亮色背景
- 控制中心激活态改为白色
- 修复网络磁贴展开态深色模式适配
- 音量/亮度条激活区域圆角
- 控制中心背景压暗
- 自定义背景模糊半径
- ColorOS 轮廓光
- 动画式斜划线静音图标
- 修复控制中心开启/关闭动画
- 修复合并控制中心上拉动画起始位置
- 修复控制中心位移基准点
- 修复合并控制中心二次展开动画
- 合并控制中心清空通知时保持开启
- 修改音量调节前四小格，合并为两中格或一大格

### 通知中心与状态栏体验优化

- 增加浮动通知宽度
- 增大通知圆角
- 恢复原生通知下滑展开
- 通知操作按钮改为黑白色
- 恢复原生第三方通知图标
- 合并双卡信号
- 独立显示网络制式
- 隐藏睡眠模式/VPN/定位/蓝牙/投屏/热点/屏幕录制/摄像头使用/麦克风使用图标
- 定制状态栏字体、字重、字间距

### 锁屏体验优化

- 限制息屏显示移动范围
- 定制锁屏和息屏时钟字体、字重、字间距

### 隐藏应用相关功能

- 支持从桌面彻底隐藏任意应用，支持启动隐藏的应用，不影响应用功能

### 导航与手势

- 多任务上划彻底结束进程
- 多任务隐藏未在运行的应用
- 修改系统长按超时
- 微调系统动画时长

### 系统净化相关功能

- 应用商店屏蔽开屏广告
- 应用商店去除精选 tab、游戏 tab、应用页所有内容、大家都在用、魅友安利、每日推荐
- 应用商店去除搜索框热词、搜索页推荐
- 应用详情去除同机型用户喜爱、所在专题、应用评测
- 天气去除应用贴片广告、屏蔽生活建议页内容推荐、首页背景压暗
- 安装器跳过安装警告

### 存储管理功能

- 可选择不自动创建媒体文件夹：Alarms、Audiobooks、Movies、Notifications、Podcasts、Recordings、Ringtones

### 停用应用相关功能

- 在应用管理中隐藏已停用的应用
- 已停用及用户级卸载应用列表备份至脚本
